# Интерактивная книга — план (v2, замена капсул)

> **Контекст.** Первая версия («Мой путь» / капсулы: island-карта, 11 слоёв, AI-генерация emoji-контента из PDF) отклонена заказчиком. Новая модель: **страница учебника остаётся страницей учебника** (скан книги как есть), но задания можно выполнять **прямо поверх страницы**. Никаких абстрактных островков — ученик видит настоящую книгу и заполняет упражнения на ней. Пилот — один модуль Access 1.

## Решения (зафиксированы 2026-07-02)

- **Снести всю капсульную систему полностью, включая 5 таблиц в удалённой БД.** (Авторизовано пользователем.)
- **Механизм наложения интерактива — гибрид:** рендер каждой страницы PDF → PNG в Storage → Gemini-vision размечает упражнения (нормализованные bbox 0..1 + тип + ключ) → админ-редактор правит дрейф координат → студент решает поверх картинки.
- **Проверка ответов — гибрид:** закрытые типы (пропуск/выбор/да-нет/сопоставление) сверяются ключом на сервере мгновенно; открытые/устные → Gemini (`geminiGenerateContent`).
- **Пилот = один модуль** Access 1 (Book `a0000000-…-001`, Module `…-101`, PDF `/books/access-1-gb.pdf`).

## Phase 1 — Интерактивная книга (пилот)

### Данные (3 таблицы, RLS по `Student.userId`)
- `BookPage`: id, moduleId FK, pageNumber, imageUrl, imageWidth, imageHeight, orderIndex.
- `PageExercise`: id, pageId FK, kind (`BLANK|CHOICE|TRUE_FALSE|MATCH|SHORT_TEXT|ORAL`, TEXT+CHECK), bbox (x,y,w,h — нормализ. 0..1), prompt, options jsonb, answerKey jsonb, orderIndex.
- `PageAttempt`: id, studentId FK, exerciseId FK, response jsonb, isCorrect bool, aiFeedback jsonb, createdAt; UNIQUE(studentId, exerciseId).
- `Module` +`pageCount int`.

### Backend
- `POST /api/admin/books/render-pages` — принимает PNG-блобы страниц (рендер на клиенте из `BookPdfViewerInner`), кладёт в `books` bucket `pages/{moduleId}/{n}.png`, вставляет `BookPage`.
- `POST /api/ai/detect-exercises` (admin) — Gemini-vision по PNG страницы → draft `PageExercise` (bbox+kind+prompt+answerKey+options).
- `POST /api/book/check-answer` — гибрид: закрытые сверяем ключом, открытые → Gemini; пишем `PageAttempt`.

### Frontend
- `entities/book`: типы `BookPage`/`PageExercise` + `useBookPages` (fetch pages+exercises по moduleId; saveAttempt).
- `widgets/interactive-book/BookOverlayEditor.vue` — картинка страницы + перетаскиваемые/масштабируемые боксы, правка типа/ключа, add/delete, save (админ).
- `widgets/interactive-book/InteractiveBookReader.vue` — стопка страниц-картинок как книга + позиционированные инпуты по bbox; «Проверить» → инлайн ✓/✗ + фидбек; лёгкий полиш (зелёная подсветка, confetti при полностью верной странице).
- `app/pages/admin/interactive-book.vue` (nav «Интерактивная книга»), `app/pages/student/book/[moduleId].vue` (nav «Учебник»).
- `features/book-exercises/useBookExercises` — мультишаг submit→check→persist.

### Проверка (end-to-end)
1. `pnpm dev` → админ: рендер страниц модуля → PNG в Storage, `BookPage` заполнены.
2. Админ: «Разметить AI» → черновые боксы; поправить в редакторе; сохранить.
3. Студент `/student/book/{moduleId}` → страницы как книга, поля на местах; заполнить; «Проверить» → мгновенный ✓/✗ (ключ) + AI-разбор (открытые).
4. `pnpm typecheck` + eslint зелёные.
