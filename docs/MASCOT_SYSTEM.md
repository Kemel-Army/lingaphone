# Маскот Lingaphone — Линг

Линг — визуальный проводник по платформе. Он появляется там, где помогает понять следующий шаг, а не используется как случайное украшение.

## Состояния

| Состояние | Роль | Основное место |
|---|---|---|
| `welcome` | Приветствие и знакомство | Первый экран |
| `platform-guide` | Объяснение экосистемы | Возможности платформы |
| `method-teacher` | Обучение и объяснение | Методика, страница «О нас» |
| `progress-analyst` | Анализ результата | Кабинет родителя, тест уровня |
| `celebrate` | Празднование усилий | Маркет достижений |
| `encourage` | Спокойная поддержка | Преподаватели и безопасная среда |
| `plan-helper` | Помощь с выбором | Форматы и цены |
| `onboarding-guide` | Следующий шаг | Запись и филиалы |
| `faq-curious` | Поиск ответа | FAQ и контакты |
| `trial-invite` | Финальное приглашение | CTA пробного урока |

## Правила использования

- Не больше одного крупного маскота в одном экране.
- Поза всегда должна объяснять функцию соседнего блока.
- Маскот не перекрывает заголовок, цену, поле формы или основную кнопку.
- На мобильном используем размеры `xs` и `sm`; `lg` допустим только в финальном CTA.
- Повторные появления декоративные и имеют пустой `alt`; смысловые появления получают короткое описание.
- Исходники на хромакее сохраняются как `*-chroma.png`, сайт использует `*-transparent.png`.

## Компонент

Использовать `LandingMascot` с обязательным `state`. Доступны размеры `xs`, `sm`, `md`, `lg`, подпись `label`, зеркальное отражение `mirror` и режим загрузки `loading`.

```vue
<LandingMascot
  state="progress-analyst"
  size="sm"
  label="Здесь нужна небольшая тренировка"
/>
```
